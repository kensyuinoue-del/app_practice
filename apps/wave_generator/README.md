# Wave Generator v0.0

指定した条件の音声波形をプレビューし、PCM WAVファイルとして保存するQt Widgetsアプリです。

## 機能

- 正弦波、矩形波、三角波、のこぎり波の生成
- 周波数、長さ、振幅、サンプルレート、チャンネル数の指定
- 生成設定に追従する波形プレビュー
- 保存前の音声再生と停止
- WAVファイルの生成と`waves`フォルダへの保存

## 操作項目

| 項目 | 設定範囲・選択肢 | 初期値 |
| --- | --- | --- |
| 波形 | 正弦波、矩形波、三角波、のこぎり波 | 正弦波 |
| 周波数 | 1～20,000 Hz | 440 Hz |
| 長さ | 0.1～60.0秒、0.1秒刻み | 2.0秒 |
| 振幅 | 0.00～1.00、0.01刻み | 0.03 |
| サンプルレート | 8,000、16,000、22,050、44,100、48,000、96,000 Hz | 44,100 Hz |
| チャンネル | モノラル、ステレオ | モノラル |
| ファイル名 | 拡張子`.wav`は省略可能 | `tone.wav` |

周波数は、選択したサンプルレートの半分（ナイキスト周波数）未満にする必要があります。振幅はデジタルのフルスケールに対する倍率です。`0.00`は無音、`1.00`は最大振幅です。

## 波形プレビュー

グラフには音声の先頭から最大20 msを表示します。音声の長さが20 ms未満の場合は全体を表示します。周波数・波形・長さ・振幅を変更するとプレビューも更新されます。ウィンドウサイズを変更してもグラフの縦横比は維持されます。

「プレビュー再生」で現在の波形を再生し、再生中に同じボタンを押すと停止します。設定を変更した場合も再生は停止します。試聴には既定の音声出力デバイスの形式を使うため、サンプルレートとチャンネルの選択は試聴には反映されず、保存するWAVにのみ適用されます。

## WAV出力

- 非圧縮PCM、符号付き16-bit
- モノラルは1チャンネル、ステレオは2チャンネル
- ステレオの左右には同じ波形を書き込みます
- ファイル名に`.wav`がなければ自動で追加します
- 出力先は`apps/wave_generator/waves`です。フォルダがない場合は保存時に作成します
- 同名ファイルがある場合は置き換えます

## ビルド

前提: CMake、C++17対応コンパイラー、Qt 6のWidgetsおよびMultimediaモジュール。

リポジトリのルートで実行します。

```powershell
cmake -S . -B build
cmake --build build --target Wave_Generator
```

ビルド後の実行ファイルは`build/apps/wave_generator/Wave_Generator.exe`です。

Windowsでコンソールウィンドウを表示しない実行ファイルを作る場合は、Qtに対応するコンパイラーを使い、構成時に`-DWAVE_GENERATOR_GUI_SUBSYSTEM=ON`を指定してください。Qtとは異なるMinGWコンパイラーを使うと、GUI実行形式のリンクに失敗する場合があります。
